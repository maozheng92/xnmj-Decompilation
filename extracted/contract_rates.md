# 战姬征召概率（客户端表）

来源：`AllConfig.bytes` 的 `ContractProbabilitySettingLO` / `ContractRewardSettingLO`。
实际抽取走 `DG.ContractModule.SendSummon`，由服务器返回 `ContractSummonResult`。改 APK 里的权重只会改展示，不会改线上结果。

圣辉 = UR（60 碎片合成）。

## 界面展示（普通征召 type=1）

| 档位 | 展示概率 |
|------|----------|
| SSR 战姬 | 1.2% |
| SR 战姬 | 3.7% |
| R 战姬 | 7.5% |

界面没有单独列出 UR。

## 界面展示（高级征召 type=2）

| 档位 | 展示概率 |
|------|----------|
| SSR 战姬 | 2.5% |
| SR 战姬 | 7.5% |
| R 战姬 | 15% |

文案：高级征召必得圣辉战姬。`GameTips`：10 连保底必得圣辉。保底池 `9985` 只有关羽 / 伊丽莎白 / 德川家康。

## 整卡权重池 1001（整只战姬）

总权重 7722。UR 合计 **0.350%**。

| 品质 | 权重占比 |
|------|----------|
| UR | 0.350% |
| SSR+ | 0.971% |
| SSR | 1.943% |
| SR | 31.987% |
| R | 64.750% |

UR 分卡：伊丽莎白 0.13%，德川家康 0.13%，关羽 0.09%。天照、武神不在该整卡池。天照走限定唤影「晴光祭」，见 `qingguang_festival.md`。
