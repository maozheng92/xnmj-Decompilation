## 马超不要唤魂战鼓

唤魂战鼓（SQ_150049）：任意召唤物死亡 → 佩戴者**魔防穿透** +4%，最多 10 层。马超和幻影打的是物理（`damageType` 1，技能写「物理伤害」）。魔防穿透只在「造成魔法伤害时无视目标魔法防御」生效，物理吃不到。

幻影 12 秒一换、受伤 +35%，确实会频繁死，但叠的是给**法伤**用的穿透。这件应该给关羽或貂蝉当换装，不是给马超。

马超这池子里对得上的是：夺魂之魄（击杀叠攻）、渐悟之锋（普攻每 10 秒 +20%，最多 3 层）、穿心之刺（暴击 → 破甲 9.8%，6 秒）。没有绯红千舞。

## 不要戴

| 圣器 | 原因 |
|------|------|
| 唤魂战鼓 → 马超 | 魔防穿透，物理吃不到 |
| 悲悯之月 → 曹植 | 佩戴者每掉 1% 血，主动治疗效率 −0.5%，七步诗会被自己的掉血惩罚 |
| 均衡之杖 → 关羽 / 武神 / 貂蝉 / 伊丽莎白 | 技能无法暴击，和她们的终结技暴击升级对着干 |
| 落日熔金 / 暴击针剂 → 黄忠 | 人会离场，周围光环浪费 |
| 净茗拂尘 | 只加木抗，这队用不上 |
| 圣洁长矛 / 辉空剑 / 噬光盾 | 要光属性伤害或光抗；9 人技能里没有稳定光伤（武神「神光」写的是物理伤害） |
| 燕返 | 招架反弹给前排能用，但德川用落日熔金或夜行之刃更值 |
