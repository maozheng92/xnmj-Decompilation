# 现有圣器：9 人佩戴

池子按你手头的来，**不用**村雨丸·斩、剥辉黑金枪、唤灵祭纸。其余：唤魂战鼓、巨食之杖、落日熔金、均衡之杖、朽忍·大剑、不屈之心、逐北弓、无暇者、冥界之握、噬光盾、伐由之拳、荣耀剑盾、绝影之刃、二重奏、燕返、诀别剑、穿心之刺、净茗拂尘、夜行之刃、回环洋流、夺魂之魄、夺魄之触、鱼肠剑、瘴气之扇、鬼切、圣洁长矛、追击者、暴击针剂、处决巨镰、辉空剑、天狼碎星、悲悯之月、渐悟之锋、日出拂晓。

没有青龙偃月刀、童子切安纲、龙胆亮银枪、战神鼓、绯红千舞、莲心圣华、碧海潮生。一人一件，同名不重复。数字是技能 1 级。

## 马超不要唤魂战鼓

唤魂战鼓（SQ_150049）：任意召唤物死亡 → 佩戴者**魔防穿透** +4%，最多 10 层。马超和幻影是物理，魔防穿透吃不到。鼓给关羽打首领，或和貂蝉换绝影。

## 不要戴

| 圣器 | 原因 |
|------|------|
| 村雨丸·斩 / 剥辉黑金枪 / 唤灵祭纸 | 按你的要求不进这套 |
| 唤魂战鼓 → 马超 | 魔防穿透，物理吃不到 |
| 悲悯之月 → 曹植 | 佩戴者掉血会降低主动治疗，七步诗被罚 |
| 均衡之杖 → 关羽 / 武神 / 貂蝉 / 伊丽莎白 | 技能无法暴击 |
| 落日熔金 / 暴击针剂 → 黄忠 | 人会离场 |
| 净茗拂尘 | 只加木抗 |
| 圣洁长矛 / 辉空剑 / 噬光盾 | 要光属性；武神「神光」是物理伤害 |
