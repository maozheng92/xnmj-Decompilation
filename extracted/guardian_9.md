# 现有 9 人队的守护灵

规则：每名战姬只戴 1 只（`HeroGuardianWearInfo`：战姬 id + 守护灵实例）。同一只实例不能给两人；表里没有塔罗那种「同名只能 1 人」的限制，普通种可以多只同名。开服第 3 天且通关主线第 12 章解锁。

全表 16 种、292 档。12 种普通灵各 24 档（品质 2–5、资质 5–15），只有面板、没有技能，宝石槽 1 个。3 只至尊（鲲 / 哈奴曼 / 刻耳柏洛斯）和 1 只传世应龙能升到 12 星、宝石槽 2 个。**只有应龙带技能**（亢龙无悔 1–5 阶）。

黄忠会离场，不要把应龙给他。武神、伊丽莎白会跳后排，应龙的护盾仍能自己吃，但「挨打产盾再分给残血」更适合站着挨打的关羽。

## 推荐佩戴（满档 / 满星）

| 战姬 | 守护灵 | 品质 | 满星面板（生命 / 物攻 / 魔攻 / 物防 / 魔防） | 为何这样戴 |
|------|--------|------|-----------------------------------------------|------------|
| 关羽 | 应龙 | 传世 | 630 / 670 / 670 / 650 / 650 | 全表最双攻，又是唯一技能。关羽前排法坦一直挨打，把伤害转护盾、分给残血、护盾期回能并反弹物理。 |
| 武神 | 哈奴曼 | 至尊 | 600 / 630 / 630 / 580 / 580 | 次席双攻。武神跳进敌阵，要的是魔攻/物攻，不是站桩产盾。 |
| 德川家康 | 鲲 | 至尊 | 630 / 580 / 580 / 600 / 600 | 生命最高档。前排拉人、吃控制，先活着把人拉进炼狱。 |
| 刘备 | 刻耳柏洛斯 | 至尊 | 580 / 600 / 600 / 630 / 630 | 双防最高档，中排不跳。苍雷阵眼和蜀汉 5 都要他活着。 |
| 伊丽莎白 | 蛤蟆丸 | 传说 | 233 / 233 / 244 / 233 / 228 | 普通种最高魔攻。跳后排吃物理多，偏物防的那档蛤蟆丸。 |
| 貂蝉 | 九色鹿 | 传说 | 233 / 233 / 244 / 228 / 233 | 同样满档魔攻，偏魔防。后排法师。 |

至尊三只 12 星仍无技能，差距就是上面这套面板。传说普通种满档大约 244，大约是应龙双攻的 36%。有至尊/传世就先给前四格。

| 星 | 阶 | 效果 |

## 缺灵替换

同时没有哈奴曼、刻耳柏洛斯（仍有应龙和鲲）时，把鲲从德川改给武神，刘备用青鸟：

| 战姬 | 改戴 | 原因 |
|------|------|------|
| 关羽 | 应龙（不动） | 技能位不让 |
| 武神 | **鲲** | 剩下那只至尊双攻 580，远好过传说 244 |
| 刘备 | **青鸟** | 满档物防 244，最接近刻耳柏洛斯的站桩位 |
| 德川 | **猫又** | 鲲让走后补满档生命 |
| 曹植 | **迦楼罗** | 猫又让给德川后，用另一只生命种 |
| 伊丽莎白 / 貂蝉 / 马超 / 黄忠 | 不变 | 蛤蟆丸、九色鹿、巴斯特、毕方 |

单缺时：

- 应龙 → 哈奴曼给关羽；武神改戴鲲（不要直接蛤蟆丸）
- 哈奴曼 → 鲲给武神，德川改猫又
- 鲲 → 德川用猫又 / 迦楼罗（满档生命）
- 刻耳柏洛斯 → 刘备用青鸟 / 稻荷神狐（满档物防）
- 至尊一只都没有 → 武神蛤蟆丸，德川猫又，刘备青鸟
- 传说魔攻不够两只：优先伊丽莎白，貂蝉用黑熊精 / 牛金牛（均衡档）
- 不要把应龙、鲲给黄忠

普通种按末两档特化选：01/02 生命（猫又 / 迦楼罗），03/04 物攻（巴斯特 / 毕方），05/06 魔攻（蛤蟆丸 / 九色鹿），07/08 物防（青鸟 / 稻荷神狐），09/10 魔防（食铁兽 / 当康），11/12 均衡（黑熊精 / 牛金牛）。每种里编号小的偏物防，编号大的偏魔防。

## 洗练（传说及以上 4 条，锁 2 条）

词条品质 7 的上限：会心率 20%、会心伤害 40%、造成伤害 12%、抗会心 30%、会心减免 60%、减伤 12%、技能命中 / 急速 30%、治疗 / 受治疗 30%。锁 2 条（`WORD_LOCK_LIMIT`）。

输出位（关羽、武神、伊丽莎白、马超、黄忠、貂蝉）：造成伤害、会心率、会心伤害、技能命中或急速。

前排（德川，关羽可混 1 条）：减伤、抗会心、会心减免。

曹植：治疗量 / 受治疗，再补减伤或抗会心。

## 符石（宝石）

玩家 60 级开第 1 槽，120 级开第 2 槽。普通种 `maxSlot` 为 1，永远只能 1 颗；应龙和三只至尊能 2 颗。同名符石不能嵌在同一只守护灵上（`SAME_TYPE_GEM_HAS_INLAY`）。

| 位置 | 符石 | 原因 |
|------|------|------|
| 关羽 · 应龙 | 磐石 + 华影 | 磐石让应龙护盾 +30%；华影 8 秒一轮水系范围伤。备选圣体（放大招叠免伤）或不休狩猎（前两次大招回能）。 |
| 武神 · 哈奴曼（或缺时改鲲） | 不休狩猎 + 华影 | 跳斩靠终结技。鲲也是两槽，符石不变。不要拿凝护（和应龙同款掉血转盾，叠不上技能档）。 |
| 德川 · 鲲 | 金蝉脱壳 + 回响 | 免一次控制并给护盾；回响奶残血。改戴猫又后只剩 1 槽，留金蝉脱壳。 |
| 刘备 · 刻耳柏洛斯 | 祝祷 + 回响 | 中排给自己和最高防友军叠免伤 / 命中。改戴青鸟后只剩 1 槽，留祝祷。 |
| 伊丽莎白 / 貂蝉 | 华影或激荡 | 只有 1 槽，法术范围伤。 |
| 马超 | 碎石或裂界 | 物理，带晕。 |
| 黄忠 | 冥痕或碎石 | 很多符石是「开场 8 秒后」才放，他可能已经离场；选普攻触发的。 |
| 曹植 | 回响或祝祷 | 治疗 / 给增益。 |

灵圃、哨所文案里的「可上阵 1/2/3 只」是农田守卫槽，不是战斗穿戴。
