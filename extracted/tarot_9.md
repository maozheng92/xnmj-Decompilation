# 现有 9 人队的塔罗牌

规则：每名战姬只戴 1 张；同名只能给 1 人。全表 16 张，升星百分比全卡相同，差别在技能和等级白字。品质：史诗 4（月亮 / 星星 / 太阳）→ 传说 5 → 传世 7 → 至尊 8。有高的先给高的。

黄忠会离场，光环队卡不要给他。武神、伊丽莎白会跳后排，只把「挂在敌人身上」的光环给他们。

## 缺卡替换

- 愚者 → 太阳 / 倒吊人 / 恶魔（给关羽）
- 世界 → 死神 / 魔术师 / 月亮（给德川）
- 节制 → 教皇（给武神，光环 DOT 跟进后排）
- 正义 / 力量 → 太阳、教皇、恶魔
- 命运 → 星星 / 女祭司（打回复队用女祭司：敌方回血 -12%）
- 不要把愚者、力量、节制、世界戴在黄忠身上

## 洗练（4 条，锁 2 条）

输出位（关羽、武神、伊丽莎白、马超、黄忠、貂蝉）：造成伤害、会心率、会心伤害、技能命中或技能急速。

前排（德川，关羽也可混 1 条）：减伤、抗会心、会心减免。

曹植：治疗量 / 受治疗，再补减伤或抗会心。
